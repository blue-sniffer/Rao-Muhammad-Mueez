# Portfolio project

- UI is built with shadcn + React Bits.
- Before writing any animated or decorative component (backgrounds, text animations, cursor effects, cards, buttons), use the react-bits skill / shadcn MCP and install it from the `@react-bits` registry.
- Only write custom code if no React Bits component fits, and say why.
- Default flavor: TypeScript + Tailwind (TS-TW).
## Component libraries
- Two shadcn registries are available: @react-bits and @aceternity (skills: react-bits, aceternity-ui).
- For any animated or decorative component, check both libraries first and pick whichever fits the design best. Say which you chose and why.
- Only write custom code if neither library has a fitting component, and say why.
- Never use two animated backgrounds on one page.
- Do not read or print .env.local.
